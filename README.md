# Kyle Kane — AI Operations Systems Builder

Public portfolio site: case studies and an interactive demo proving operational system design — not a coding-language or AI-tools showcase.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | What it is |
| --- | --- |
| `/` | Overview — positioning, three case-study cards, CTA |
| `/work/receipt-reconciliation` | Hero case study — document intake → extraction → exception queue → close package (LedgerLens workflow design) |
| `/work/maintenease` | CMMS case study — live product at [maintenease.com](https://maintenease.com), early-stage honest framing |
| `/work/service-request` | Case study + **clickable interactive demo** of the sprint deliverable (sample data, no backend) |
| `/how-i-work` | Eight-step method, Operational AI Workflow Sprint™ offer, contact |

## Stack

- Next.js 15 (App Router) + TypeScript + Tailwind CSS v4
- Static pages + client components for the service-request demo
- No database required

## Design

Calm operational aesthetic — paper/ink/steel palette, serif headings, one muted accent. Mobile-first. No stock photos.
